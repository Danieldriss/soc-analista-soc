# Análisis de logs

Esta carpeta contiene los casos prácticos principales del proyecto.

Cada caso representa un escenario habitual dentro de un entorno SOC e incluye el análisis de los eventos generados, las técnicas de detección y las posibles acciones de respuesta.

## Casos incluidos

* SSH Brute Force
* Phishing
* Malware Execution
* Suspicious PowerShell Activity
* C2 Connection
* Nmap Reconnaissance

## Metodología utilizada

Todos los casos siguen la misma estructura:

1. Contexto
2. Escenario simulado
3. Evidencias
4. Análisis
5. Detección
6. Respuesta
7. Explicación para estudio
8. Puntos clave

El objetivo es facilitar tanto el aprendizaje como la consulta posterior de cada escenario.
